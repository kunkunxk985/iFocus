# iFocus 人工验收清单（约 5 分钟）

**版本目标**：与 `Build/iFocus.app` 一致（设置页底部可见版本号）。  
**环境**：macOS 13+ · 本机 Application Support 数据可保留（勿在验收中清空，除非测备份）。

```bash
bash Scripts/package_app.sh && open Build/iFocus.app
```

勾选：`[ ]` → 通过时改成 `[x]`。异常请记：**步骤 / 期望 / 实际 / 截图**。

---

## 0. 启动与壳（30s）

| # | 步骤 | 期望 | ☑ |
|---|------|------|---|
| 0.1 | 打开 App | 主窗出现，无闪退；侧栏 + 专注钟默认可见 | [ ] |
| 0.2 | 看左上角红绿灯 | 三颗按钮齐全，不压进内容区白边 | [ ] |
| 0.3 | 收起侧栏 | 窄轨 ≥ 红绿灯宽；› 展开钮 + 小头像；再展开恢复 | [ ] |
| 0.4 | Dock / 菜单栏 | 菜单栏有番茄图标（仅 .app 包）；Dock 可点回前台 | [ ] |

## 1. 专注钟核心（60s）

| # | 步骤 | 期望 | ☑ |
|---|------|------|---|
| 1.1 | 选任务或自由专注 → 空格开始 | 状态「进行中」；圆环/倒计时走；播放键变暂停 | [ ] |
| 1.2 | 空格暂停 | 「已暂停」；会话仍算进行中（改设置时长不应抹掉） | [ ] |
| 1.3 | 模式 chips：短休 / 长休 | **运行中不可切**；暂停/空闲可切；选中色跟模式 | [ ] |
| 1.4 | 专注模式选中色 | 与设置「强调色」一致（不是固定番茄红） | [ ] |
| 1.5 | ⌘→ 跳过 | 进入下一段，**不**增加今日番茄 / 记录 | [ ] |
| 1.6 | ⌘R 重置（进行中） | 确认框；确认后清会话、不记入历史 | [ ] |
| 1.7 | 沉浸模式 | 环与控制保留；再退回完整 UI | [ ] |

| # | 步骤 | 期望 | ☑ |
|---|------|------|---|

| 2.2 | 再打开 | 弹窗「恢复专注会话？」；可区分上次退出 / 异常文案 | [ ] |

| 2.4 | 点「恢复」 | 进专注钟，暂停态，任务/剩余时间合理 | [ ] |
| 2.5 | （可选）再测「丢弃」 | 横幅消失；无幽灵会话 | [ ] |

## 3. 清单 · 添加 / 编辑 / 撤销（60s）

| # | 步骤 | 期望 | ☑ |

| 3.2 | 排期 chip「明天」再加一条 | 任务 due=明天；今天列表不应出现（除非逾期逻辑） | [ ] |

| 3.6 | 删除一条 → toast「撤销」 | 6s 内撤销恢复；过期后不可恢复 | [ ] |
| 3.7 | 批量选中删 2 条 → 撤销 | 两条都回来 | [ ] |
| 3.8 | 置顶 / 拖拽排序 | 置顶沉顶；拖拽后顺序保持（刷新列表仍在） | [ ] |
